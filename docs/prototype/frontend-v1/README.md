# Guide Flow 前端原型 v1

这是用于验证产品基础逻辑的可点击原型，不是生产前端代码。

## 启动

在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory docs/prototype/frontend-v1
```

然后打开：

```text
http://localhost:4173/?variant=A
```

## 原型方案

- `variant=A`：家庭讲解桌，左右分栏，接近当前静态原型；
- `variant=B`：任务轨道，强调当前阶段和下一步动作；
- `variant=C`：讲义翻页，强调逐步阅读和讲解节奏。

底部的“逻辑控制”仅用于快速验证状态，不属于最终产品界面。

## 可验证流程

1. 点击“开始示例”；
2. 使用“模拟下一阶段”推进处理状态；
3. 在“待确认”状态修改题目并确认；
4. 进入讲解后切换 3 个步骤；
5. 点击“听我讲”验证朗读；
6. 在相似题中输入 `12` 或其他答案验证反馈；
7. 点击“失败”验证重试和重新上传。
