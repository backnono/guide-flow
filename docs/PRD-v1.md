# 讲给我听：小学数学家庭辅导 Agent

版本：v0.1（MVP）  
日期：2026-09-01  
目标用户：辅导小学五、六年级孩子作业的长辈与家长

## 1. 背景与问题

长辈常常面对两个困难：题目本身不会做，或虽然会做却无法用孩子当前能理解的方式讲解。现有拍题产品偏向直接给出答案，不能充分支持“怎么教”。

## 2. 产品目标

用户上传一道数学题后，产品在一个闭环内完成：识别题目 → 用户确认 → 生成符合小学高年级知识范围的分步讲解 → 通过图文和简单动态视觉帮助理解 → 给出一道相似题巩固。

## 3. MVP 范围

### 必须有

- 题目图片上传入口，支持 JPG、PNG
- 题目识别结果展示与文字修改
- 题型/年级/知识点标签
- 3 步以内的分步讲解
- 简单动态演示：比例条、分组、线段等基础视觉
- 普通话朗读入口
- 一道相似练习题与答案检查
- 明确展示“识别清楚度”和当前讲解阶段

### 暂不做

- 复杂 3D 或完整动画视频生成
- 任意题型的自动搜索与多来源内容聚合
- 登录、历史记录、家长/孩子多账号
- 在线支付、教师审核、社交分享
- 自动批改整页作业

## 4. 用户主流程

1. 用户进入页面，选择上传照片或体验示例题。
2. 系统展示识别出的题目，用户可以修改 OCR 文本。
3. 系统标记题型、年级和知识点。
4. 用户按“听我讲”或左右翻页查看每一步。
5. 用户完成相似题，输入答案并获得即时反馈。

## 5. 体验与内容要求

- 默认先解释“题目条件”和“为什么这样做”，再展示算式。
- 不跳过关键中间步骤，不使用明显超纲的方法。
- 语言短句化、口语化，适合长辈照着讲给孩子听。
- 允许重复听和回到上一步。
- 任何识别不确定的内容都必须要求用户确认，不能静默猜测。

## 6. MVP 验收标准

- 首屏 5 秒内能理解产品用途和下一步操作。
- 示例题可从开始走到练习反馈，不依赖后端服务。
- 上传图片后能看到已选择状态，并提示当前为演示识别。
- 讲解共有 3 个步骤，前后切换、进度点和朗读均可操作。
- 输入 12 时练习题反馈正确，其他输入提示重新思考。
- 移动端宽度下主要内容不溢出，上传、讲解、练习仍可完成。

## 7. 下一版技术与产品验证

- 接入 OCR，输出题干、公式、表格和几何图形结构。
- 使用数学计算器/符号校验器二次验证答案。
- 根据年级与已学知识约束解法。
- 将讲解结构化为“题意 → 关键关系 → 算式 → 检查”，再由前端渲染动态视觉。
- 访谈 5 位实际辅导孩子的长辈，重点验证：是否敢照着讲、孩子是否能复述关键步骤。
